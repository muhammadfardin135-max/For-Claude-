# Raw source files

Drop files here that you own and want the agent to read directly — PDFs,
exported transcripts, course notes, ebooks you bought.

This is the clean path for paid material. The agent will not circumvent a
paywall, but it will happily read a copy you legitimately have.

Reference them in `corpus/sources.yaml` as `url: "local: corpus/raw/<file>"`.
